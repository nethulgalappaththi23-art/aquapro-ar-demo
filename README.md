# AquaPro Bottle: AR Product Demo

An AR product demo built with A-Frame and AR.js. Show the Hiro marker to the camera to see the product on a display stand.

**Live demo:** PASTE-YOUR-LINK-HERE

## Features
- Marker scene: cylinder stand, sphere, box, 3D model and text labels
- Animation: the bottle rotates and the ball moves up and down
- Interaction: tap the ball to change its colour (color-change); tap the INFO box to show or hide the product details (features-toggle, our own component)
- Status banner: a script checks whether the marker is visible and changes the banner text and colour (red = lost, green = found)
